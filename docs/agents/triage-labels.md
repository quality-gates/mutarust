# Triage labels

| Skill role        | GitHub label      | Meaning                                 |
| ----------------- | ----------------- | --------------------------------------- |
| `needs-triage`    | `needs-triage`    | A maintainer must assess the issue      |
| `needs-info`      | `needs-info`      | The reporter must give more information |
| `ready-for-agent` | `ready-for-agent` | An agent can do the specified work      |
| `ready-for-human` | `ready-for-human` | A person must do the work               |
| `wontfix`         | `wontfix`         | The project will not do the work        |

When a skill specifies a role, use its GitHub label.
